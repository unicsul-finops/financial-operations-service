# Architeture Decision Record - Example:

# ADR-001: Utilizar Java e Spring Boot

## Status

Aceita

## Contexto

Precisamos escolher a tecnologia do microsserviço.

## Opções consideradas

- Java com Spring Boot
- C# com ASP.NET
- Node.js com NestJS

## Decisão

Utilizaremos Java com Spring Boot.

## Consequências

- A equipe precisará conhecer Java.
- Teremos suporte do ecossistema Spring.
- A aplicação terá maior consumo de memória.
